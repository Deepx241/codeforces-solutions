On the contrary, if it exists, remove it. </li></ul> </li></ul><p>A graph is called <span class="tex-font-style-it">cool</span> if and only if one of the following holds:</p><ul> <li> The graph has no edges, or </li><li> The graph is a tree. </li></ul><p>You have to make the graph <span class="tex-font-style-it">cool</span> by performing the above operations. 10^5\right)$$$) — the number of vertices and the number of edges.</p><p>Then $$$m$$$ lines follow, the $$$i$$$-th line contains two integers $$$u_i$$$ and $$$v_i$$$ ($$$1\le u_i,v_i\le n$$$) — the two $$$2\cdot 10^5$$$.</p><p>It is guaranteed that there are no self-loops or multiple-edges in the given graph.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For distinct integers $$$a$$$, $$$b$$$, and $$$c$$$ ($$$1\le a,b,c\le n$$$) — the three integers you choose in the $$$i$$$-th operation.</p><p>If there are multiple solutions, you can output any of
